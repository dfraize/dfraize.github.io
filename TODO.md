## Reference

- Deploy: `bash deploy-safe.sh "commit message"` — runs `optimize-images.js`, `sync-partials.js`, `generate-cards.js`, and `generate-resume-pdf.js` automatically, then commits and pushes.
- New project page: ask Claude to use the `new-portfolio-page` skill, or just say "create a new portfolio page."
- Resume PDF: `resume.html`'s "Download PDF" button links to `Douglas-Fraize-Resume.pdf`, which `generate-resume-pdf.js` (Puppeteer) regenerates from `resume.html` on every deploy — edit the HTML, not the PDF.
- Portfolio/homepage cards: edit `projects-data.json` (see its `_schema` block), then run `npm run generate-cards` — never hand-edit the `<a class="portfolio-card...">`/`<a class="work-card...">` blocks in `portfolio.html`/`index.html` directly, they get overwritten. The homepage's 3 featured cards are auto-picked as the most recent by `date`; `featured: true` breaks a tie in favor of that project for the homepage specifically. Ties in the full grid always break alphabetically by title.
